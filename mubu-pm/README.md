# 思维导软件 AI 智能总结 — 产品需求文档

> 为思维导软件（大纲笔记 + 思维导图工具）规划的 AI 智能总结功能产品需求文档与交互原型。

## 项目简介

本项目为思维导软件的 **AI 智能总结** 功能编写完整的产品需求文档（PRD）、交互原型和业务流程图。用户在文件列表页即可看到每个大纲文件的 AI 自动摘要，降低信息筛选成本，建立 AI 产品心智。

### 核心功能

- **AI 自动生成内容摘要**：基于大纲层级结构，逐层提炼主旨，生成 2-3 句自然语言摘要
- **7 种状态标签体系**：已总结 / 已更新 / 生成中 / 无法总结 / 失败 / 大文件摘要 / 编辑中
- **完成度智能判断**：综合时间窗口、内容闭合度、节点数三个维度判断是否触发总结
- **隐私双模式**：支持本地处理（端侧 AI）和云端处理（加密 API），用户自由选择
- **大文件聚焦总结**：节点超过 50 个时自动切换聚焦模式，优先提炼核心内容
- **编辑后自动刷新**：用户修改大纲后自动重新生成摘要，标签变为"已更新"并脉冲提示

### 战略定位

- **AI 总结 = 免费基础功能**（留存拉新，建立 AI 心智）
- **AI 一键生成思维导图 / AI 优化大纲结构 = 付费增值功能**（后续变现）

## 快速浏览

1. **PRD 文档**：在浏览器中打开 `requirements/prd_v1.1_final.html`，左侧有导航目录，支持版本切换
2. **交互原型**：在浏览器中打开 `prototypes/prototype_v1.1.html`，展示 9 种文件列表状态，支持状态筛选、隐私切换、失败重试等交互
3. **流程图**：查看 `flows/flowchart_v1.1.md`，包含主线流程、更新触发、完成度判断、异常处理、隐私选择、大文件聚焦、空状态边界等 7 张 Mermaid 图

## 技术栈

- **文档**：纯 HTML/CSS，内嵌 Mermaid 流程图渲染
- **原型**：HTML + Tailwind CSS CDN + Vanilla JavaScript
- **流程图**：Mermaid (Markdown 格式)

## 用途

本项目为个人产品学习研究用途，旨在练习产品需求文档撰写、交互原型设计和业务流程图绘制能力。
